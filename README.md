# Insta Browser Client

Локальный Instagram-клиент со скачиванием медиа. Работает через настоящий Chrome: вы один раз входите в Instagram в открывшемся окне, а приложение забирает ленту, профили и посты из этой же браузерной сессии. Пароль приложение не хранит и в приватный API Instagram не ходит, поэтому блокировки API и cookie-вход его не касаются.

Интерфейс повторяет светлый веб-дизайн Instagram: узкий сайдбар с иконками, истории, лента карточками с автором и лайками, правая колонка с рекомендациями, модалка поста. Медиа проксируются через локальный сервер, поэтому картинки и видео не ломаются из-за CORS и CORP.

## Что умеет

- вход в свой аккаунт через окно Chrome, сессия сохраняется между запусками;
- две ленты: «Подписки» (домашняя лента Instagram) и «Рекомендации» (Explore — контент есть даже у пустого аккаунта; по умолчанию открывается она);
- лента обновляется сама каждые 45 секунд, при возврате на вкладку и по кнопке «Обновить»; показывается время последнего обновления, новые посты отмечаются тостом;
- сетка постов с автором и лайками;
- профиль по никнейму: аватар, подписчики, посты;
- просмотр поста: карусель, фото и видео прямо в приложении;
- скачивание отдельных файлов и всего медиа из поста;
- кнопка «Скачать все посты» в профиле: клиент листает профиль до конца, вытаскивает медиа каждого поста (фото, видео, карусели) и складывает файлы в `downloads/<ник>/`, показывая прогресс и кнопку «Открыть папку»;
- свой профиль: аватар и ник в сайдбаре и правой колонке, переход в свой профиль, кнопка «Открыть в Instagram»;
- Instagram-мелочи: двойной тап по фото — сердечко, стрелки между медиа и постами, `Esc` закрывает пост, кнопка «Ссылка» копирует адрес поста;
- индикатор VPN в интерфейсе: IP, страна и провайдер текущего выхода;
- всё работает локально: сервер слушает `127.0.0.1:3000`.

Если аккаунт, в который вы вошли, ни на кого не подписан, Instagram отдаёт в «Подписки» только suggested-посты (иногда два). Это не ошибка клиента: откройте вкладку «Рекомендации» или подпишитесь на аккаунты в Instagram.

## Требования

- Windows, Node.js 18+ и установленный Google Chrome;
- VPN в **системном режиме** (Happ, Amnezia, Outline и т. п.). Клиент запускает собственный Chrome, поэтому VPN из расширения браузера ему не поможет — нужен туннель на уровне системы, как у вас сейчас (`happ-xray`).

## Запуск

Двойной клик по `start.bat` — он поставит зависимости (при первом запуске), запустит сервер и откроет `http://127.0.0.1:3000`.

Вручную:

```powershell
cd instaClient
npm install
npm start
```

Проверка парсера: `npm test`.

## Первый вход

1. Включите VPN и убедитесь, что в браузере открывается instagram.com.
2. Нажмите **«Войти в Instagram»** — откроется окно Chrome.
3. Войдите в аккаунт (можно с 2FA и подтверждением входа).
4. Когда сессия появится, окно закроется само, а клиент загрузит ленту.

Сессия хранится в `data/browser-profile` и переживает перезапуск приложения. Кнопка «Выйти» удаляет профиль браузера.

## Как это устроено

- `server.js` — Express-сервер и API.
- `src/browser.js` — Playwright управляет Chrome: вход, навигация, перехват JSON-ответов Instagram, скачивание файлов.
- `src/extract.js` — вытаскивает посты и медиа из JSON, который отдаёт сам Instagram: находит узлы с `code`, `media_type`, `image_versions2`, `video_versions`, карусели и вложенные структуры.
- `public/` — интерфейс на чистом HTML/CSS/JS без сборки.

Посты берутся из тех же запросов, которые делает веб-интерфейс Instagram после вашего входа. Если Instagram поменяет разметку или структуру ответов, парсер в `src/extract.js` может потребовать правки.

## Если что-то не работает

- **«Нужно войти» после перезапуска** — сессия Instagram могла истечь или отозваться. Войдите заново.
- **Лента пустая** — включён ли VPN, открывается ли instagram.com в Chrome. Попробуйте «Обновить»; при повторной ошибке выйдите и войдите снова.
- **Instagram просит проверку безопасности** — завершите её в открывшемся окне Chrome, сессия подхватится автоматически.
- **Ошибка запуска Chrome** — проверьте, что Chrome установлен; при необходимости задайте `CHROME_CHANNEL=msedge`, но на этой машине Edge не проходил к Instagram через VPN, поэтому Chrome предпочтительнее.
- **Хотите видеть, что делает браузер** — запустите с `set HEADLESS=0 && npm start`: окно Chrome будет видимым (по умолчанию оно скрыто/вынесено за экран).

## Безопасность и ограничения

- Профиль Chrome в `data/` содержит cookie Instagram — не выкладывайте проект целиком в публичный репозиторий.
- Приложение работает только на вашей машине и не отправляет данные наружу, кроме запросов к Instagram и `ipinfo.io` (для индикатора VPN).
- Автоматизация Instagram нарушает его пользовательское соглашение; используйте для личных задач и своего аккаунта.
- Скачивание идёт через сервер: файл сначала загружается на бэкенд, затем отдаётся браузеру. Для очень больших видео это занимает время и память.
